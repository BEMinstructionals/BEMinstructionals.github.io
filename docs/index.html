What is the BEM File Editor?
The BEM File Editor is a modern editor for *.idf files, which are the Input Data File (IDF) files for the EnergyPlus whole building energy simulation program. The BEM File Editor installers do not contain any version of the EnergyPlus simulation program. Each version of EnergyPlus you want to use must be installed separately.



Why release the BEM File Editor and YouTube videos for free?

Very simple. I work as a consultant for EnergyPlus projects with the BEM File Editor and YouTube videos serving as free advertising. (See the BEM Instructionals Consulting section of this website or use mitchaldichter@beminstructionals.com to contact me directly.) Tabs & Features







General
  • Multiple EnergyPlus Versions - A single installation can open multiple EnergyPlus IDF versions via a simple drop down menu to choose the version number.
  • BSD 3-Clause License - Free open-source permissive license similar to the EnergyPlus license.
  • Modern User Interface - Vector graphics based fonts, choice of font family, and font point size.
  • EV Code Signing Certificate - Verifies the publisher of software, confirming both the identity of the publisher and the integrity of the code.

  • Detect if the *.idf on disk have been modified by some other program since opening in the BEM File Editor.
  • Help menu links to useful resources, like the I/O Reference, for the currently selected EnergyPlus version.
EnergyPlus console Tab
  • Simulates the current IDF and EPW file with the selected EnergyPlus version.
  • Shows real-time console output of the EnergyPlus engine.
  • Button to terminate the current simulation.
  • Keyboard shortcut (Shift + Space) to start simulation.
Editor Tab
  • Two object tables for easy copy-pasting of fields between objects in different classes.
  • Find and replace text in object fields.
  • Undo and redo with history and preview of changes.
  • Search feature for field choices like nodes, object names, et cetera.
  • Right-click on an object text field displays options for the input, like minimum, default, autosize, and Field Choices.
  • New, Delete, Copy, and Paste buttons for objects.
  • Toggle between SI and IP units.
  • Highlights incorrect cells.
Geometry Tab
  • View building geometry defined by the vertices of objects.
  • The exterior and interior side of a surface are a darker and lighter shade to verify that the object vertex order matches the specified EnergyPlus vertex order.
  • Pan, rotate, and zoom with mouse.
  • Alternatively specify the camera position and center of view in the left menu.
  • Compatible with BuildingSurface:Detailed, FenestrationSurface:Detailed, Shading:Site:Detailed, and Daylighting:ReferencePoint objects.
  • Toggle Axes, Wireframe of hidden surfaces, and Implicit Surfaces (REVERSED prefix).
  • Left selection tree can toggle surface groups based on object fields.
  • Useful for checking all surfaces have the intended Construction, Zone, Surface Type, Outisde Boundary Condition, Sun Exposure, Wind Exposure.
  • Displays 3D axes x, y, z as red, green, blue and the North Axis as orange.
Node Connections Tab
  • Draggable text boxes for objects, nodes, and fields with pan and zoom.
  • Selector for all existing objects with node name fields.
  • Field text boxes can be automatically or manually placed.
  • Double-click text box to display all connected nodes/objects.
  • Right-click text box to show/hide individual connections.
  • Useful for graphing an example *.idf you didn't create.
  • Make a loop from scratch and view as you go.
  • Finding errors in the graph is much easier than following node names in object fields.
Text Output File Tab
  • Display file in the *.idf directory in plain text.
  • Text search on the file.
  • File names can be specified in View->Application Settings.
CSV Output File Tab
  • Display file in the *.idf directory as a table of CSV cells.
  • Text search on the file.
  • File names can be specified in View->Application Settings.
HTML Output File Tab
  • Display file in the *.idf directory as a webpage.
  • Text search on the file.
  • File names can be specified in View->Application Settings.

Example IDFs and Documentation in the EnergyPlus Installation Directory

The "ExampleFiles" directory contains IDFs that showcase how to use particular objects in an EnergyPlus model. This gives a working example that you can then migrate to your own IDF file.

The "Documentation" directory has files like EngineeringReference.pdf, GettingStarted.pdf, InputOutputReference.pdf, and others. The most useful file overall is probably the InputOutputReference.pdf, but it's more of a reference. Some of the other files are more helpful when first starting to use EnergyPlus.

Prototype Models Created by the Government

For years, the DOE has funded the creation and updating of building models in EnergyPlus. These building models cover a variety of commercial and residential building types, meant to be representative of a significant portion of all existing buildings in the US. The models are updated periodically to simulate energy savings associated with changes in energy codes and standards.

For researchers, the models are useful as base models to investigate changes in construction, equipment, and controls on energy use and utility bills. Two of the most useful parts of each building model are the overall geometry and schedules specified in the IDF file. Researchers can have confidence that the parts of the model that can't easily be calculated or looked up, such as the behavior of people in the building and thermostat setpoints, were rigorously investigated for each building type.

DOE Commercial Reference Buildings
The above linked site has prior versions of the building models, split up into Pre-1980, Post-1980, and New Construction last updated in 2012. The PNNL models built upon the DOE models and added some new building types.
References and citations can be found as comments in the IDF files opened with a basic text editor.

PNNL Prototype Building Models
The most recent version of the building models at the above link have three categories and multiple building types.
The IDFs were upgraded to EnergyPlus version 24.2 and then the OpenStudio Application 1.9.0 was used to displayed them.
Some IDFs had the text "For: " removed from some Schedule objects in order to be imported into the OpenStudio Application.
References and citations can be found as comments in the IDF files opened with a basic text editor.

You'll notice some of the building geometries in the models have floating floors, missing rooms, or both. This was intentional to speed up simulation time by explicitly modeling a single thermal zone and then using the Multiplier field in some objects to account for all the duplicate thermal zones as if they were all explicitly modeled. It works, but can be tricky to get right, such as when using cooled and heated water to condition air at the terminal unit in multiplied zones. Accounting for total air flow on a shared fan, or extra water flow for a pump, can be difficult to specify correctly in the EnergyPlus model.
